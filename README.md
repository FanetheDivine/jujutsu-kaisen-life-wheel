# 咒术回战 · 抽选人生转盘

一个**零依赖的单文件网页**：转动数十轮因果轮盘，抽出一个属于《咒术回战》世界观的"人生"，
并把结果导出成 Markdown 档案，交给任意 AI 写成同人短篇。

**打开方式**：下载 `jujutsu-life-wheel.html`，双击即可在浏览器里运行。没有构建步骤、没有 npm、没有后端。

> 本作为《咒术回战》二次创作的同人向玩具 · 版权归原作者芥见下下及集英社所有 · 生成结果仅供娱乐

## 核心机制

### 1. 前轮实时改写后轮（因果链）

不是装饰性的"选项列表"，而是**真的改权重**：

- **加权**：抽到「死灭回游时期」，受肉体权重暴涨；抽到「涩谷事变」，一般市民（被卷入者）大涨。
- **归零（锁死）**：「一般人类」→ 术式轮只剩「无咒力·凡人」；「凡人」→ 领域轮只剩无领域，等级锁在五/四级；
  「天与咒缚」→ 不可能有领域（甚尔、真希之路）。
- **整轮消失**：没开出领域，「领域形态」这一轮直接标注为「此轮不存」，档案里以「——（此轮不存）」呈现。
- 转轮上方实时显示「前轮因果干涉」清单，每项列出规则名与 `↑/↓ 多少 pp`，选项行右侧还有 ▲▼ 对比基础几率。

### 2. 扇区面积 = 当下几率

转盘不等分，按当前 pct 累加切割；落点角度在目标扇区内随机偏置，旋转角按 `rot + 圈数×360 + Δ` 反算，
必定停在抽中的那一块。极窄扇区（<5°）自动隐藏文字。

### 3. 轮次队列可动态插入

流程不是静态数组，而是可 splice 的队列 `STAGES`。落地后立刻按结果长出新轮：
经历 / 缺席原因 / 技能 / 咒具数量 / 束缚链 / 战斗回合 / 黑闪追击 / 御三家家门 / 战后成长……

## 一轮人生包含什么（36–74 轮，平均约 48 轮）

| 段落 | 内容 |
|---|---|
| 起点 | 入场时期 → 性别 → 入场年龄 → 出身·存在形态 →（御三家则抽「哪一家」）→ 咒力资质 |
| 内面 | 生得术式（15 种具体术式 + 性质）→ 生得领域（有无 → 形态 → 效果 → 领域名） |
| 性能 | 六维独立轮：咒力总量 / 咒力操控 / 体术 / 体质 / 外貌 / 智谋，各 **E / C / B / A / S / SS / EX** 七档并带原作注释 |
| 刻度 | 咒力等级评定（五级 E … 特级 SS、特级上 EX）、努力程度、性格、运气、特殊天赋、束缚链、羁绊 |
| 经历 | 按入场时期动态插入：百鬼夜行 / 少年院 / 涩谷事变 / 死灭回游 / 新宿决战 / 终战之后；抽到「缺席」会再抽**缺席原因**（含「已死」，会锁死其后所有经历） |
| 技艺 | 先抽掌握几个技能 → 逐个抽（简易领域 / 反转术式 / 黑闪 / 极之番 / 咒灵操术 / 十种影·调伏 / 咒具锻造 …）；抽到「咒具锻造」再抽做了几件、每件是什么 |
| 决战 | 决战阵营 → 交手回合数（1–5，三回合最常见；评级 SS/EX 自动 +1）→ 每回合双方各抽一手 → 结算 |
| 宿傩专项 | 首次击败宿傩 → 抽他是否**解放原身**（四臂双面）→ 若是则开**二番战**（专属招式组：四臂斩击「解」/ 火焰箭「竈」/ 再次展开「伏魔御廚子」）；持有「狱门疆」时还有一次性的封印一击 |
| 终局 | 战后是否成长（学会新技能 / 术式进化 / 等级提升 / 失去某样东西）→ 命运结局 → 后世评价 |

### 战斗演出

每一招都有威力值并累计成分差，**结算盘的扇区直接按分差换算**——"你打了什么"真实改变胜率。
黑闪命中后可再抽两次追击（上限 4 次）。对手招式按羁绊编排（宿傩 = 解/开/伏魔御廚子，五条 = 无量空处/茈/赫/苍，甚尔 = 游云/拆解术式……）。
回合太多可以用「跳过战斗演出 · 直接结算」。

### 立场一致性

「决战阵营」先抽，后面的涩谷 / 死灭回游 / 新宿决战 / 终战之后的经历都会跟着它走——
新宿决战的冲突选项会被直接锁死（显示为「无缘」），不会出现"决战是高专方、新宿却站在宿傩一侧"。

## 抽完之后能做什么

1. **咒力检定**：六维条 + 综合战力（/100，换算成字母）+ 生还倾向百分比。
2. **术式名 / 领域名 / 称号**：按本次结果做种子生成（如「雷孕」术式、「无间赐死」（未完）、「狱门的祓除者」），同一份人生结果永远同名。
3. **导出 Markdown 档案**（复制 / 下载，可直接粘给任何 AI）：
   此身档案表 · 六维字母表 · 技能与咒具与束缚 · 逐段经历 · 缺席原因 · **逐回合战斗记录**（一番战 / 二番战分开）·
   决战结果 · 战后 · 结局 · 后世评价 · 世界观锚点 · 写作指令。
4. **接你自己的 API**：页面内填 Base URL / Model / API Key，走 OpenAI 兼容 `/chat/completions`（支持流式逐字输出）。
   密钥只存本机 `localStorage`。系统提示词可在页面内改，且明确禁止 AI 篡改你的结局——它只能写"你如何走到这个结局"。

## 交互与无障碍

- 点击转盘**中央的「呪」**即可转动（也支持 Tab 聚焦后按 Enter / 空格）。
- 三个快捷键口：**跳过此轮** / **一键抽完余生** / **跳过战斗演出 · 直接结算**。
- **重新开始**按钮（轮盘区、顶栏、终局页底部各一个）一键回到第一轮，并作废所有在途的旋转 / 连抽 / 流式输出。
- WebAudio 咔哒声（默认关），右上角可切换**夜行性**（深色主题），尊重 `prefers-reduced-motion`。

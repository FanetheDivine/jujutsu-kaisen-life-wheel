# 咒术回战 · 抽选人生转盘

转动数十轮因果轮盘，抽出一个属于《咒术回战》世界观的“人生”，并把结果导出成 Markdown 档案，交给任意 AI 写成同人短篇。

项目使用 **Vite + 严格 TypeScript + vite-plugin-pwa** 构建，是可直接部署到静态托管服务的可安装 PWA；运行时不依赖后端。

**当前版本：`v6.0`**（2026-10-15 · 多场战斗 + 战后成长 + 早死分支）

**在线直接玩**：<https://solar-cv.github.io/jujutsu-kaisen-life-wheel/>

旧地址 <https://solar-cv.github.io/jujutsu-kaisen-life-wheel/jujutsu-life-wheel.html> 会自动跳转到新版首页。

## 核心机制

### 前轮实时改写后轮

不是装饰性的选项列表，而是真正修改后续抽选权重：

- **加权**：抽到「死灭回游时期」，受肉体权重上升；抽到「涩谷事变」，一般市民（被卷入者）权重上升。
- **归零**：一般人类无法获得术式，凡人无法获得领域，「天与咒缚」也会排除领域。
- **整轮消失**：没开出领域时，「领域形态」直接记为「此轮不存」，档案里以「——（此轮不存）」呈现。
- 转轮上方实时显示「前轮因果干涉」清单及每项概率变化，选项右侧显示相对基础几率的变化。

### 扇区面积等于当前几率

转盘按当前概率累加切割，而非等分。落点角度在目标扇区内随机偏置，再按旋转圈数与目标角度反算最终角度。极窄扇区会自动隐藏文字。

### 动态轮次队列

流程使用可动态插入的 `STAGES` 队列。每轮落地后会按结果加入经历、缺席原因、技能、咒具、束缚、战斗回合、黑闪追击、御三家家门与战后成长等后续轮次。

## 一轮人生包含什么

一轮通常包含 **36–74 轮，平均约 48 轮**：

| 段落     | 内容                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| 起点     | 入场时期、性别、年龄、出身与存在形态、御三家家门、咒力资质                   |
| 内面     | 生得术式及性质、生得领域及其形态、效果与名称                                 |
| 性能     | 咒力总量、咒力操控、体术、体质、外貌、智谋，独立按 E–EX 七档抽选             |
| 刻度     | 咒力等级、努力、性格、运气、特殊天赋、束缚与羁绊                             |
| 经历     | 百鬼夜行、少年院、涩谷事变、死灭回游、新宿决战与终战之后；缺席还会继续抽原因 |
| 技艺     | 技能数量与具体技能；抽到咒具锻造后继续抽咒具数量与具体咒具                   |
| 事件战   | 在场即可开战，敌人按立场、阵营与强度匹配；战后抽成长与失去                   |
| 决战     | 决战阵营、回合数、双方逐回合出招与结算；评级较高时自动增加回合               |
| 宿傩专项 | 首次击败宿傩后可能解放原身并进入二番战；狱门疆提供一次性封印机会             |
| 终局     | 战后成长、命运结局与后世评价                                                 |

黑闪命中后可追加攻击。可以跳过单场战斗演出，也可以开启「事件战只出结算」。若角色在事件战中战死，后续经历会强制缺席，不再参加最终决战，结局也会锁定为相应的早死分支。

## 抽完之后能做什么

1. **查看检定**：六维、综合战力与生还倾向。
2. **生成名称**：按本次结果确定性生成术式名、领域名与称号，同一结果始终同名。
3. **导出 Markdown**：复制或下载完整档案，包含逐段经历、逐回合战斗、一番战与二番战、终局和写作指令。
4. **接入自己的模型**：页面内填写 Base URL、Model 与 API Key，调用 OpenAI 兼容 `/chat/completions`，支持流式输出与中断。
   API 配置只保存到本机 `localStorage` 的 `jjkwheel` 项；系统提示词可以自行修改。

## 交互与无障碍

- 点击转盘中央的「呪」，或聚焦后按 Enter / 空格，即可转动。
- 支持跳过此轮、一键抽完余生、跳过战斗演出与重新开始。
- 重新开始会作废在途旋转、自动连抽与流式输出。
- WebAudio 咔哒声默认关闭；支持浅色 / 深色主题与 `prefers-reduced-motion`。

## 本地开发

### 环境要求

- Node.js `>=22.12.0`
- pnpm `10.32.1`（`packageManager` 已固定）

```sh
pnpm install
pnpm dev
```

打开 Vite 输出的本地地址。开发服务器仅用于本地开发，不是模型 API 代理。

### 常用命令

| 命令                | 用途                                     |
| ------------------- | ---------------------------------------- |
| `pnpm dev`          | 启动 Vite 开发服务器                     |
| `pnpm build`        | 严格类型检查并生成 `dist/`               |
| `pnpm preview`      | 本地预览生产构建                         |
| `pnpm typecheck`    | TypeScript 严格类型检查                  |
| `pnpm lint`         | ESLint 检查                              |
| `pnpm format`       | Prettier 格式化                          |
| `pnpm format:check` | Prettier 格式检查                        |
| `pnpm test`         | 运行 Vitest 测试                         |
| `pnpm test:watch`   | 监听模式运行测试                         |
| `pnpm check`        | 依次执行格式、类型、lint、测试与生产构建 |

现有测试覆盖确定性随机工具，以及应用初始化、跳过轮次、重新开始与主题切换等关键 DOM 回归场景。

## PWA 与离线

- 通过 HTTPS 或 localhost 打开后，浏览器可将其安装到桌面或主屏幕，以独立窗口运行。
- 首次成功联网打开后，Service Worker 会预缓存构建后的 HTML、JavaScript、CSS、Manifest、图标与兼容跳转页，此后可离线打开应用外壳并抽选人生。
- 使用自动更新策略；新版本 Service Worker 安装后会接替旧版本。
- **离线不代表离线生成 AI 故事**：模型请求仍直接访问用户填写的 API 地址，不被 Service Worker 缓存，也不经过项目代理。
- 直接双击源码 HTML 不会获得 Service Worker；请使用 `pnpm preview` 或 HTTPS 部署验证 PWA。

## 构建与 GitHub Pages

```sh
pnpm build
pnpm preview
```

生产文件输出到 `dist/`。Vite 使用 `base: './'`，因此可部署在 GitHub Pages 的项目子目录，不必把资源路径写死到域名根目录。

`.github/workflows/deploy.yml` 会在 `main` 分支推送后安装依赖、执行生产构建并发布 `dist/`。首次使用时，在仓库 **Settings → Pages** 中将 Source 设为 **GitHub Actions**。

旧 `jujutsu-life-wheel.html` 的源码位于 `public/jujutsu-life-wheel.html`，只负责跳转，不再包含业务代码。

## 版本

版本号显示在网页标题旁与页脚，也会写进导出的 Markdown 档案，由 `src/app.ts` 中的 `VERSION` / `VERSION_DATE` / `VERSION_NOTE` 维护。

- **v6.0**（2026-10-15）：全部事件战、按立场与强度匹配敌人、战后成长、早死分支及「事件战只出结算」。
- **v5.x**：御三家细化、立场冲突修复、复制反馈修复、「重新开始」与束缚链修复。
- **v4**：具体术式、领域、技能与咒具，新增多类角色设定转盘。
- **v3**：E–EX 分级、年龄盘、缺席原因、逐回合战斗、技能、咒具与战后成长。
- **v2**：加权扇区、可点击中枢、经历长链、六维与决战判定。
- **v1**：十轮因果转盘。
